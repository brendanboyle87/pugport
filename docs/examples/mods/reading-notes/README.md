# Reading notes

Write notes about what you're reading, right next to the chat. **Add latest reply** quotes the newest answer into your notes. **Discuss in chat** puts your notes in the message box so you can ask about them; nothing is sent until you send it. Notes save as you type and stay with this chat. Open the chat any time with **Chat** or Ctrl+J. It can read this chat and write drafts. It never sends messages for you.
